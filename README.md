# Escala-de-Apgar-
La escala de Apgar evalúa rápidamente la condición del recién nacido al minuto y a los 5 minutos de vida, mediante cinco criterios que suman de 0 a 10.

Elaborado por: Britany Sherlyn Agular Acevedo

Referencias (APA):
Apgar, V. (1952). A proposal for a new method of evaluation of the newborn infant. Current Researches in Anesthesia & Analgesia, 32, 260-267.
